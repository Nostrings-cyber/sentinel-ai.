SENTINEL AI 🛡️

AI-powered security guard for NEAR autonomous agents.

SENTINEL AI protects AI agents from dangerous blockchain transactions.

Before an AI agent sends money or interacts with a smart contract, SENTINEL checks the destination for suspicious activity.

How it works

- ALLOW: The transaction passes security checks.
- WARN: The transaction needs human approval.
- BLOCK: The transaction is dangerous and must be stopped.

1. Recipient Intelligence Engine
2. Risk Scoring Engine

4. Transaction Authorization Guard
